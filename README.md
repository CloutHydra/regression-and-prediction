# Regression and Prediction Coursework

Two Python exercises from coursework exploring linear regression, feature scaling, coefficient interpretation, and simple prediction.

## Projects

### California Housing Regression
Uses scikit-learn's California Housing dataset to:
- fit a linear regression model on the original features;
- standardize both the feature matrix and target;
- refit the regression model on standardized data; and
- compare raw and standardized coefficients to examine relative feature influence.

Run:
```bash
python california_housing_regression.py
```

### Input/Output Linear Regression
Uses a small input/output dataset and SciPy's `linregress` to:
- return an exact output when an entered input already exists; or
- predict an output using the fitted regression line for a new input.

Run:
```bash
python input_output_regression.py
```

## Skills Demonstrated
Python, NumPy, pandas, SciPy, scikit-learn, linear regression, standardization, data handling.

## Context
These programs were completed as part of university coursework and are published here as examples of Python/data-analysis practice.
